# VectorMind

VectorMind is a RAG-powered chatbot that lets you upload PDFs and ask questions about them in natural language. Answers are generated by Anthropic Claude, grounded in your documents via FAISS vector search — built with Streamlit and LangChain.

**Live app:** [vectormind.streamlit.app](https://vectormind.streamlit.app)

## How it works

1. Upload one or more PDFs in the sidebar and click **Process Documents**.
2. The app extracts the text, splits it into chunks, and embeds them into a FAISS vector store using a local HuggingFace model (`all-MiniLM-L6-v2`).
3. Ask a question — the most relevant chunks are retrieved and sent to Claude, which answers grounded in your documents, with conversation memory.

## Run locally

```bash
pip install -r requirements.txt
```

Create a `.env` file in the project root:

```env
ANTHROPIC_API_KEY=your_anthropic_api_key
CLAUDE_MODEL=claude-sonnet-4-6
```

Then start the app:

```bash
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Push this repo to GitHub.
2. Create a new app at [share.streamlit.io](https://share.streamlit.io) pointing at this repo, branch `main`, main file `app.py`, Python version **3.12**.
3. In the app's **Settings → Secrets**, add:

```toml
ANTHROPIC_API_KEY = "your_anthropic_api_key"
CLAUDE_MODEL = "claude-sonnet-4-6"
```

Note: uploaded documents are indexed in memory on the server. The vector store does not persist across app restarts — re-upload PDFs after a restart.

## Project structure

| File | Purpose |
